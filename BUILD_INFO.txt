KissKH v1.0.12 — TV Season Matching Build

Changes:
- Keeps v1.0.10 exact-title movie lookup.
- Keeps v1.0.11 reusable video-key cache.
- Adds TV season-aware title matching for KissKH entries stored per season.
- Example: VUEO "Reacher" S2 selects "Reacher - Season 2".
- Season 1 accepts the bare base title and prefers an explicit "Season 1" entry when present.
- Season 2+ requires an explicit matching season suffix.
- Episode selection requires the requested episode number exactly.
- Search remains one title query; season filtering is local and does not add search requests.

Validation:
- manifest valid
- provider syntax valid
- source/runtime byte-identical
- Reacher S2E3 regression: 1 search, 1 detail, correct season/episode stream

Build note:
- esbuild is not installed in this environment. src/kisskh/index.js and providers/kisskh.js are already byte-identical and self-contained, so the validated runtime provider is packaged directly.
